# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Tabletop roleplayers using a computer or phone, including offline sessions.

## Product purpose

PolySheet keeps imported game systems, character sheets, resources, dice history
and encounters in a local browser archive.

## Capabilities and constraints

React/TypeScript PWA, Dexie persistence, no backend, account or analytics.
Imported rules remain immutable. Unsupported automation stays visible.
The visual redesign must preserve existing functions, data and compatibility limits.

## Brand commitments

Keep the PolySheet name and Italian UI. The user supplied
`stitch_sheetcore_ttrpg_companion_interface.zip` as the visual reference and
confirmed dark by default with a light option. Saved theme choices remain intact.
They later requested centered dialogs on both device sizes and removal of the
workspace switcher, top-right online/local/profile indicators, sidebar version
footer and privacy promotional panels. Keep backup controls and installation.

## Evidence on hand

The supplied archive contains desktop/mobile screenshots, HTML and a
Contemporary Grimoire design guide. Its characters and metrics are illustrative,
not app data or verified capabilities. External game fixtures are local-only.
